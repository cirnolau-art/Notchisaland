# NotchIsland

原生 macOS 灵动岛工具，把音乐、系统提示和常用操作集中到屏幕顶部的刘海区域。

## 功能

- 自动显示 Music、Spotify 等播放器的歌曲、封面、进度和播放控制
- 自动获取实时歌词，支持滚动、逐字高亮、自动换行和省资源模式
- 音量、亮度、输入法、电源和系统通知提示
- AirPods 左耳、右耳和充电盒电量
- 专注模式、倒计时和闹钟
- 音频输出设备查看与切换
- 日历事件和会议倒计时
- 快捷打开应用、文件夹和 macOS 快捷指令
- 文件暂存和可选的剪贴板历史
- 纯黑和 macOS 原生液态玻璃外观
- 每个模块都可以单独关闭

## 系统要求

- macOS 15 或更高版本
- Apple Silicon arm64
- macOS 26 及以上显示液态玻璃设置

## 安装

从 [Releases](../../releases) 下载 DMG，将 NotchIsland.app 拖到“应用程序”文件夹。

当前发布包为本机 ad-hoc 签名。首次启动时，按需要在“系统设置 → 隐私与安全性”中允许辅助功能、蓝牙、日历和自动化权限。

## 使用

点击或悬停顶部灵动岛即可展开。展开后可以点击模块图标切换页面，也可以使用横向滑动切换模块。

所有功能都可以在“设置”中单独开关。macOS 15 不显示液态玻璃入口。

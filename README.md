# NotchIsland 1.5.0

原生 macOS 灵动岛，最低支持 macOS 15，同时适配 macOS 26；macOS 26 及以上可使用原生液态玻璃。

## 操作

- 指针停留 0.3 秒：摘要预览；点击两侧胶囊或预览：展开。
- 音乐 / 暂存 / 专注 / 声音 / 日程 / 快捷 / 剪贴板：点击顶部图标或横向滑动切换，悬停查看名称。页面切换使用可中断弹簧、交叉淡入与轻微侧向位移。
- Esc、点击外部或顶部收起按钮：收起。指针、拖动和输入期间不自动收起。
- 拖放文件到顶部胶囊：自动展开暂存区。拖出使用，双击或空格预览，按钮支持 Finder 定位和系统分享。
- 暂存最多 30 项，仅存引用；移除记录和清空暂存不会删除原文件。
- 计时支持快捷时长、自定义 1–1440 分钟、暂停、继续、加时与重启恢复。Mac 睡眠期间按截止时间继续计算，醒来后提示到点；不会唤醒关机或睡眠的 Mac。
- 音乐的进度条可拖动。Music / Spotify 支持元数据、封面与播放控制；其他来源使用系统 MediaRemote 作为尽力兼容，不能保证系统版本和播放器均支持。
- 自动跟随播放来源，不再显示播放器选择器。暂停后波形收为直线，约 2.5 秒后两侧收回；指针离开时音乐面板也会收起。启动时已有暂停曲目不会撑宽刘海。
- 窗口按屏幕完整边界贴顶；空闲外形使用实际刘海宽高。音量和亮度提示仅延展两侧，保持刘海原有厚度。
- 音量、亮度硬件读写在后台串行队列执行；进度填充与外形使用可中断的 Core Animation 动画，内容随外形裁切。
- 设置支持指定显示器、全屏行为、按应用 Bundle ID 隐藏、自动收起时间、轻柔动效和登录启动。

## 第二批功能

- **AirPods**：通过蓝牙连接事件触发双耳弹簧入场动画，分别显示左耳、右耳和耳机盒电量。连接时每 60 秒读取系统报告；未连接不轮询。电量未报告时显示“—”；缓存值明确标记，不伪造实时电量。菜单栏和“设置 → 设备与通知”可查看或预览。
- **刘海通知（兼容桥接）**：使用辅助功能观察 NotificationCenter 的新横幅，将可识别的通知显示到刘海。成功显示后才尝试关闭原横幅，忙碌时短暂排队。不会读取通知数据库，不保存或记录通知正文。需要保留来源应用的系统横幅，系统勿扰及隐藏的通知不转发。此功能受系统辅助功能结构限制，不能保证接管所有应用或彻底消除原横幅短暂出现；未授权、读取失败或显示受限时保留系统行为。
- **声音输出**：通过 CoreAudio 事件更新输出列表，显示当前设备、切换状态，以及每台设备是否支持系统调音量。固定音量的 HDMI、数字及部分虚拟设备禁用滑块，明确提示在设备端调节。设备切换失败保留错误信息，垂直滚动列表不会误触收起。
- **日历与会议**：默认关闭，在“日程与快捷”或刘海日程页连接系统日历，申请 EventKit 完整读取权限。查看未来 7 天中最近的定时日程（包含尚未结束的日程）；跳过全天、取消和当前用户拒绝的项目。开始前 5 分钟提醒；识别 Zoom、Google Meet、Teams、Webex、腾讯会议和飞书等链接，点击加入，否则打开系统日历。只读取，不写入。通过 EventKit 变化、唤醒和单次截止时间定时器更新；15 分钟兜底，页面展开时每 15 秒更新文字。
- **快捷操作**：最多 6 个应用、文件夹或系统快捷指令，可在设置中添加、排序和移除。应用和文件夹使用系统选择器；快捷指令按需读取，不轮询，使用系统 shortcuts URL 执行，不通过 shell 拼接命令。沿用快捷指令自己的权限与确认。
- **两套独立外观**：纯黑模式保持原样；液态玻璃模式使用 Apple `NSGlassEffectView`（macOS 26+），辅以原生 `NSVisualEffectView` 调节材质强度。顶部完整遮住物理刘海并保持纯黑，向下渐变到通透的原生玻璃；不再淡出玻璃本身，保留原生折射轮廓并加上细腻边缘高光。模糊和不透明度分别保存。Apple 未公开独立的玻璃模糊半径，因此“背景模糊”调节原生材质强度，不调用私有模糊滤镜。macOS 15 完全隐藏玻璃模式入口，已保存的玻璃偏好回退为纯黑，玻璃参数继续保留。系统减少透明度时也回退纯黑。
- **空闲资源**：停止无必要的指针及进度计时；空闲亮度检测降为 2 秒，播放器暂停时降为 8 秒兜底。通知使用 AX 事件，蓝牙使用连接事件。收回刘海或隐藏时释放玻璃效果并停止波形；无永久渲染循环或屏幕截图采样。

当前 1.2 完整备份：`../NotchIsland-backup-1.2-20261109-202003`，包含源码、测试、构建目录与原应用，并提供 SHA-256 核对清单。

## 权限

Music / Spotify 使用系统“自动化”权限。媒体键接管需要在“系统设置 → 隐私与安全性 → 辅助功能”允许 NotchIsland；未授权时系统原生提示仍会出现。开启接管后会等待权限生效并自动重试，无需反复切换开关。不支持调节的设备保留系统按键行为。Option 单独组合仍打开系统设置，Shift + Option 支持细调。

AirPods 连接监听可能需要系统蓝牙权限；通知桥接和媒体键接管共用辅助功能权限。日历需要系统“日历 → 完整访问”权限，关闭功能后停止查询。
首次蓝牙授权在后台等待，不会阻塞刘海与设置窗口；拒绝权限时可从系统隐私设置重新开启。

亮度依赖 DisplayServices，不提供通用外接显示器 DDC 控制。原生全屏根据前台窗口尺寸判断；闹钟到点始终显示停止按钮。

## 构建与验证

`Version.env` 统一维护发布版本号和构建号，设置窗口与“关于灵动岛”从应用的 Info.plist 读取，DMG 文件名也使用同一个发布版本。

发布前检查主程序的执行权限、实际最低系统版本、动态库依赖和玻璃类弱链接，并移除开发机的 Xcode 运行库搜索目录。这些静态检查不能代替 macOS 15/26 实机验证。

```sh
./build-app.sh
./build-dmg.sh
swift test --disable-sandbox
swift run --disable-sandbox NotchIsland --snapshot --snapshot-output /tmp/notchisland-review
```

构建会先验证新包签名，再替换 dist 中的应用；已有应用保留为带时间戳的备份。当前为本机 ad-hoc 签名，未做 Developer ID 公证。

`build-dmg.sh` 先构建应用，再生成 `dist/NotchIsland-<版本>-<架构>.dmg` 与 SHA-256 校验文件。打开 DMG，把左侧应用拖到右侧“应用程序”即可安装。它为当前 Mac 的架构打包；`--skip-build` 可复用已构建的应用。首次打包会在 `.build/dmg-tools` 创建独立 Python 环境并安装固定版本的 dmgbuild；不进入应用，不影响运行时资源占用。安装窗口使用 Retina 背景和固定图标位置，生成过程无需控制 Finder。

应用图标资源位于 `Resources/AppIcon.icns`，打包时自动嵌入。运行 `swift scripts/generate-app-icon.swift` 可重新生成全部图标尺寸和预览。

快照模式不启动系统监听、媒体查询和真实文件暂存，输出黑色、玻璃、耳机、通知、隐私、声音、日程、快捷操作和旧系统设置布局等 46 张界面快照，并检查激活后的实际贴顶坐标、刘海厚度、暂停波形与控件复用。`--selftest` 提供只读系统能力诊断。

## 1.4 验证边界

本机为 Apple Silicon、macOS 27.2，已做真实系统横幅读取、显示、去重与原生关闭验证；修复全屏滚动容器、无关闭按钮、自定义关闭动作与桌面小组件耗尽遍历预算的问题。兼容旧系统的 header / title / body 和 AXNotificationCenterAlert 结构，浏览通知中心历史时不转发。通知识别日志只记录次数和动作结果，不记录正文。

二进制最低系统版本为 15.0，NSGlassEffectView 弱链接，26/27 API 均有可用性保护；旧系统设置布局有模拟快照。当前没有 macOS 15/26 实机或虚拟机，不能把部署版本检查等同于这些系统的完整实测。音频实测仅有内置扬声器；AirPods Pro 系统报告可读左右耳和盒子缓存，当前未连接，其他耳机不承诺兼容。日历授权后的真实账户读取、会议跳转及多设备切换需在相应权限/设备可用时验证。

本轮改动前备份：`artifacts/revision4/source-before.tgz` 和 `artifacts/revision4/NotchIsland-before.app`。

只读/受控诊断（终端运行构建出的可执行文件，避免改变安装版权限）：

```sh
.build/release/NotchIsland --diagnose-audio
.build/release/NotchIsland --diagnose-notifications
```

通知诊断会发送一条本机脚本编辑器测试横幅，验证刘海显示、去重及原横幅移除，生成 `/tmp/notchisland-live-notification.png`，不导出其他通知。构建采用本地 ad-hoc 签名，更新代码后系统可能要求重新开启辅助功能权限；以应用实际检测状态为准。

歌词、天气继续列为后续；本轮加入默认关闭的可选剪贴板历史，不引入外部数据源或额外权限。

## 启动故障诊断

M1 / M1 Pro / M1 Max 均使用 arm64 安装包。若 Finder 只显示“无法打开”，可在终端执行 `/Applications/NotchIsland.app/Contents/MacOS/NotchIsland --startup-check`（1.4.1 起支持）。该模式只验证加载并打印版本与系统信息，不启动系统监听或申请权限。`--version` 打印版本后退出；其他诊断命令也始终输出到终端。

`scripts/NotchIsland-启动诊断.command` 生成桌面诊断报告，包含系统版本、文件执行权限、签名校验、安全评估和启动退出码；不会删除隔离标记、重置权限或关闭 Gatekeeper，也不收集通知正文、歌曲或个人文件。可用 `zsh scripts/NotchIsland-启动诊断.command /应用实际路径/NotchIsland.app` 运行。

当前未持有 Developer ID 证书，安装包仍为 ad-hoc 签名；签名完整不等于已通过 Gatekeeper 或 Apple 公证。向其他 Mac 分发时仍需按系统安全界面允许，或在具备 Developer ID 后重新签名和公证。

## 1.5 模块与剪贴板

设置新增“模块”页，七个展开模块均可独立开关。入口、菜单、横向切换和悬停摘要同步更新；关闭当前模块后转到可用模块，全部关闭则回到原始刘海，点击可进入模块设置。文件暂存关闭后不再接收拖放，已有引用继续保留。专注关闭后保留已经开始的计时和响铃，菜单可停止当前计时，避免静默丢失提醒。

剪贴板默认关闭，开启后从下一次复制开始记录文字与图片，点击记录重新复制，在目标应用中粘贴；支持单条删除和全部清空。仅存在内存中，退出或关闭模块即清空，不改变系统当前剪贴板。最多 30 条、总计 16 MB；单条文字上限 1 MB、图片 4 MB，超出跳过。忽略文件 URL、保密/临时/自动生成标记，以及常见密码管理器的前台复制。无法自动识别普通文字中的敏感内容，请在复制前关闭此模块。图片列表通过 ImageIO 生成小缩略图，避免列表解码整幅大图。

音乐、日历、剪贴板、音频设备列表与即时提示均按需启停；关闭亮度提示停止亮度轮询，关闭输入法/电源提示移除对应监听。音量底层事件监听仍保留以支持声音面板与按键能力判断，没有音量轮询。快捷操作页面复用未变化的控件，避免其他声音事件打断点击。耳机和通知沿用各自的独立开关。收起时继续释放原生玻璃；轮廓与边缘高光共用可中断弹簧。

本轮备份：`artifacts/modules-glass/source-before.tgz`。测试和视觉检查位于同目录；自动快照能验证布局、材质创建/释放、遮罩几何与交互，但不能替代在不同壁纸和 macOS 26 上观察系统实时折射的效果。

## 1.5.1 AirPods 提示修正

电量读取与自动提示分开：后台刷新、读取失败后的恢复、单纯蓝牙连接均不弹出电量框。只有 Mac 声音输出新切到同一副 AirPods，并经过 2 秒稳定确认且仍保持连接，才自动展示一次。短暂重连、重复事件与启动/唤醒后的 10 秒恢复过程保持静默；同一设备两分钟内不重复提示，过期事件不补弹，忙于其他操作时也不排队。手动查看与动画预览继续保留。

macOS 公开接口不能可靠读取盒盖和佩戴状态，因此以实际声音输出切换作为开始使用的依据；仅开盖但未切为 Mac 声音输出时不会弹窗。沿用现有 CoreAudio 事件监听，未增加轮询。

新增 11 项触发策略测试，全套 55 项通过，覆盖后台刷新、地址格式、设备匹配、短暂重连、读取失败、启动/唤醒恢复、过期与冷却。发行包通过启动和最低系统版本检查；真实开盖、佩戴及自动切换行为仍需使用 AirPods 实机验证。本轮备份与验证记录位于 `artifacts/airpods-trigger-fix/`。

## 1.6.0 歌词、侧边通知与专注视觉

音乐模块现在支持本地 LRC 歌词。设置中可以关闭歌词，或选择在收起状态的刘海下方/侧边显示；展开音乐面板时会在进度控制下方显示当前行和下一行。Apple Music 风格使用轻量 Core Animation 淡入过渡，省资源模式只按约 4Hz 更新；没有匹配到 LRC 时不显示空占位。默认读取 `~/Music/NotchIsland Lyrics`，也可以在设置中选择目录，按“歌曲名.lrc”或“歌曲名 - 歌手.lrc”匹配。不会联网抓取歌词或上传歌曲信息。

系统通知新增“两侧小窗口”位置。它使用独立的无边框面板，定位在当前显示器左右下方，不改变刘海高度；点击可打开来源应用，超时自动收起。原有刘海展开模式保持不变，原生横幅只在接管成功后收起。

耳机提示恢复真实 IOBluetooth 连接事件作为回退开始使用信号，并保留 2 秒稳定确认、短重连过滤和冷却策略；如果 CoreAudio 明确显示内置扬声器等非蓝牙输出，会取消候选，避免仅打开盒盖时误弹。后台电量读取保持静默；手动“查看实际电量”会直接显示已缓存的左右耳和充电盒电量，等待中的卡片会在读取完成后替换。

专注计时继续显示在收起状态，并增加 Apple Intelligence“减少打扰”风格的蓝紫渐变标识。macOS 没有公开接口读取系统 Focus/减少打扰状态，因此这里只表示灵动岛自己的专注计时，不伪造系统状态。

# NotchIsland

原生 macOS 灵动岛工具，把音乐、系统提示和常用操作集中到屏幕顶部的刘海区域。

**1.8.4** 汇总了自 1.7.10 以来的歌词与界面改进。展开播放器可显示四行清晰歌词，普通 LRC 整句显示也能使用 RGB 或封面流光。详见 [版本更新记录](RELEASE.md#notchisland-184)。

## 功能

- 自动识别 Music 和 Spotify 的播放状态，显示歌曲、封面和进度，支持播放控制
- 优先使用本地 LRC，也可自动查找在线歌词。支持长句自动换行，以及收起状态下的上下滚动
- 展开时呈现上一句、当前句、下一句和再下一句。相邻歌词清晰可读，以亮度区分当前句
- Apple Music 风格会按歌词数据选择显示方式。有可靠逐字时间轴时，逐字渐亮、横向羽化、上浮和可选的 HDR 高亮同步变化。普通 LRC 或时间轴不可靠时整句显示
- 两种显示方式均可选 RGB 流光或封面流光。收起与展开的位置可分别设置，字号、字色和光晕可调整
- 原生液态玻璃展开外框保持连续圆角，动画过程中不会被玻璃矩形盖成直角
- 音量、亮度、输入法、电源和系统通知提示
- 音量和亮度提示由媒体键触发，系统自动调整时保持安静。两条提示可分别设置低值色、高值色和 HDR
- AirPods 左耳、右耳和充电盒电量
- 专注模式、倒计时和闹钟
- 音频输出设备查看与切换
- 日历事件和会议倒计时
- 快捷打开应用、文件夹和 macOS 快捷指令
- 文件暂存和可选的剪贴板历史
- 收起时整条贴顶纯黑，展开可选纯黑或 macOS 原生液态玻璃。展开与收起可从当前画面连续反向
- 设置窗口跟随系统浅色和深色外观，macOS 26 及以上的操作按钮使用系统 Liquid Glass 样式
- 每个模块都可以单独关闭

## 系统要求

- macOS 15 或更高版本
- Apple Silicon arm64
- 原生液态玻璃需要 macOS 26 或更高版本。较早版本和开启「减少透明度」时使用纯黑外观

## 安装

从 [Releases](../../releases) 下载 DMG，将 NotchIsland.app 拖到“应用程序”文件夹。

本地构建为 **1.8.4（构建 26）**。在仓库根目录运行 `./build-app.sh` 和 `./build-dmg.sh --skip-build`，可生成 `dist/NotchIsland-1.8.4-arm64.dmg`。

当前发布包为本机 ad-hoc 签名。首次启动时，按需要在“系统设置 → 隐私与安全性”中允许辅助功能、蓝牙、日历和自动化权限。

## 使用

点击顶部灵动岛展开，开启「悬停预览」后可停留查看摘要。展开后可点击模块图标或横向滑动切换模块，按 `Esc` 或点击收起按钮关闭面板。

在「设置 → 交互」可切换「自然滚动」，默认跟随 macOS。要让灵动岛显示音量和亮度按键提示，在「设置 → 音乐与权限」开启媒体键接管并授权辅助功能。

在「设置 → 外观」分别配置音量与亮度提示条。系统根据当前百分比在两端颜色间插值。开启 HDR 后会随调节值提高显示亮度，100% 时请求显示器支持的最大 HDR 余量。

在「设置 → 外观」里，将「展开背景」设为「液态玻璃」，再选「标准」「轻模糊」或「清透玻璃」。标准和轻模糊可调整顶部黑色渐变、色调和边缘高光。清透玻璃保留系统材质，并去掉这三层额外效果。

在「设置 → 模块」里，可以开关展开面板里的各个模块。

### 歌词设置

- 在「设置 → 音乐与权限」选择收起和展开时的歌词位置，也可以关闭在线查找或指定本地歌词目录。展开位置可选控制键下方或播放器右侧
- 在「设置 → 音乐与权限 → 歌词动画」选择「Apple Music 风格」。再到「设置 → 外观 → 歌词外观」开启 RGB 流光、封面流光或 HDR 歌词高亮。逐字 HDR 需要可靠的逐字时间轴和支持 HDR 的显示器
- 想使用简洁的整句显示时，可选择「省资源」，关闭逐字效果与流光

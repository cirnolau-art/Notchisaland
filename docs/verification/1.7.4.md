# NotchIsland 1.7.4（构建 15）验证记录

日期：2026-11-20。最低系统版本：macOS 15.0；本次本地包：arm64。

## 本次修改

- 歌词先计算有效句子，再更新背景显隐。修复前奏空背景闪烁和旧隐藏任务覆盖新歌词；淡出期间保留文字，完成后释放渲染资源。
- macOS 26 原生玻璃作为主体，默认关闭额外磨砂、人工亮边和大投影；保留摄像头黑色遮罩与向下渐变。纯黑和玻璃设置继续独立保存，减少透明度时降级。
- 双指向内捏合完全收起，向外张开恢复；向上/下双指滑动作为备用。完全收起具有独立状态，播放与换歌不会自动打开，普通提示不再吞掉系统通知。
- 字体度量决定歌词高度和基线；收起与展开共用缓存字形、时间进度和独立字词淡入。支持真实逐字时间，普通 LRC 整句提亮；省资源模式保留滚动。
- 独立 HDR 歌词开关和强度。仅高亮字形使用公开 Core Animation EDR 能力与浮点扩展线性 sRGB 图像；根据显示器当前余量限幅。光晕仍单独设置。
- 没有新增持续逐帧绘制定时器。歌词按下一时间点唤醒，暂停/隐藏/完全收起停止相应动画和刷新。
